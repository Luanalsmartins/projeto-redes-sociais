# 🧠 Projeto: Redes Sociais

Este projeto é uma aplicação de **redes sociais** desenvolvida como parte do meu aprendizado em desenvolvimento web, utilizando HTML, CSS e estrutura de navegação entre páginas.

---

## 🧩 Sobre o projeto

O objetivo deste projeto é criar uma interface simples de rede social com páginas independentes para diferentes perfis — como **Home**, **Instagram**, **Facebook**, **Twitter**, **YouTube** e GitHub — simulando a navegação básica entre telas de perfis.  
Este tipo de projeto ajuda a praticar **estrutura de pastas, organização de arquivos, links internos e uso de HTML/CSS**.

---

## 📁 Estrutura do projeto

O repositório contém:

- `index.html` — Página inicial do projeto
- Várias páginas por plataforma social (`facebook.html`, `instagram.html`, etc.)
- Pasta `estilos` — Com arquivos de CSS
- Pasta `imagens` — Ícones e imagens usados no projeto

As páginas são interligadas para simular a navegação entre diferentes perfis em uma rede social.

---

## 🚀 Como visualizar o projeto

1. Clone o repositório:
git clone https://github.com/Luanalsmartins/projeto-redes-sociais.git
2. Entre na pasta do projeto:
cd projeto-redes-sociais
3. Abra o arquivo `index.html` em um navegador (Google Chrome, Firefox, etc.)
